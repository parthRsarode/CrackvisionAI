<task id="03-02-01" type="implementation">
  <name>Integrate YOLOv8 pipeline into FastAPI with non-blocking worker threads</name>
  <description>
    1. Update `backend/app/schemas.py`:
       - Extend `AnalysisResponse` with: `has_segmentation: bool`, `polygons: List[List[List[float]]]`, `normalized_polygons: List[List[List[float]]]`, `bounding_boxes: List[List[float]]`, `defect_count: int`, `inference_time_ms: float`, `aci_compliance: Optional[Dict[str, Any]]`.
       - Preserve backward compatibility for all existing fields (`analysis_id`, `status`, `confidence`, `crack_type`, `severity`, `estimated_width`, `affected_area`, etc.).
    2. Update `backend/app/services/crack_analyzer.py`:
       - Initialize `YOLOv8SegmentationService` and `MorphometryService`.
       - In `analyze(file_bytes, filename)`: measure execution time, invoke segmentation, apply morphometry evaluation, and populate `AnalysisResponse`.
       - If PyTorch runtime raises an unrecoverable exception or weights are missing, seamlessly fall back to `_mock_analysis` with deterministic seeding, setting `has_segmentation=False`.
    3. Update `backend/app/main.py`:
       - Offload `crack_analyzer.analyze(contents, file.filename)` via `await anyio.to_thread.run_sync(...)`.
    4. Write integration test in `backend/tests/test_api.py` validating `POST /analyze` with multipart upload, verifying status code 200, schema validity, and polygon fields.
  </description>
