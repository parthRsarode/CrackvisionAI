<task id="03-01-02" type="implementation">
  <name>Implement YOLOv8SegmentationService with retina_masks and polygon extraction</name>
  <description>
    Create `backend/app/services/yolo_service.py`:
    1. Device detection: Support Apple Silicon `mps`, CUDA if available, fallback to `cpu`.
    2. Model weight resolution: Look for custom crack weights (`weights/crack_yolov8s_seg.pt`), fallback to `yolov8n-seg.pt` (auto-cached), or graceful mock simulation if PyTorch environment lacks weights.
    3. Implement `@torch.inference_mode()` `segment(image_bytes, conf_threshold=0.25)`:
       - Run inference with `retina_masks=True`, `iou=0.45`, `max_det=100`.
       - Guard against `result.masks is None` for clean images with zero cracks.
       - Extract pixel coordinates `[[x, y], ...]` from `result.masks.xy`.
       - Extract normalized coordinates `[[x/w, y/h], ...]` bounded 0.0 to 1.0.
       - Extract bounding boxes `[x1, y1, x2, y2]` and confidence percentages (0-100).
    4. Write comprehensive unit tests in `backend/tests/test_yolo_service.py` verifying device initialization, segmentation output structure, and clean-image empty mask safety.
  </description>
  <files>
    backend/app/services/yolo_service.py
    backend/tests/test_yolo_service.py
  </files>
  <verify>
    <automated>pytest backend/tests/test_yolo_service.py -v</automated>
  </verify>
</task>

<task id="03-01-03" type="implementation">
  <name>Implement MorphometryService for artifact filtering and ACI 224R aperture analysis</name>
  <description>
    Create `backend/app/services/morphometry.py`:
    1. Aspect Ratio Filter: Reject polygon candidates with aspect ratio < 1.3:1 and area > 1000px² (eliminating circular tie-holes and blocky shadows).
    2. Crack Orientation Analyzer: Compute bounding box elongation and principal axis angle (0-30° horizontal settlement, 30-60° diagonal shear, 60-90° vertical shrinkage).
    3. ACI 224R-01 Compliance Evaluator:
       - Calculate estimated aperture based on polygon width profile and calibrated reference scale.
       - Compare aperture against ACI 224R-01 Table 4.1 exposure limits (0.10 mm water-retaining, 0.15 mm marine, 0.30 mm humid, 0.41 mm dry).
       - Select ASTM C881 remediation protocol (Type I low-viscosity penetrant vs Type IV structural pressure injection).
    4. Write unit tests in `backend/tests/test_morphometry.py` validating tie-hole rejection, orientation categorization, and ACI limit checks.
  </description>
  <files>
    backend/app/services/morphometry.py
    backend/tests/test_morphometry.py
  </files>
  <verify>
    <automated>pytest backend/tests/test_morphometry.py -v</automated>
  </verify>
</task>
